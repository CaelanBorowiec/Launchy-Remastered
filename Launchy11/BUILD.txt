Launchy 3.0 is built with Qt 6 and qmake. Clone the repository and work in
the Launchy11 directory, where Launchy.pro lives:

    git clone https://github.com/CaelanBorowiec/Launchy-Remastered.git
    cd Launchy-Remastered/Launchy11

The project links the Qt 5 compatibility module (core5compat). Every kit
below needs that module installed.


Building on Linux:

For Debian and Ubuntu:

    sudo apt-get install build-essential qt6-base-dev qt6-5compat-dev libx11-dev
    qmake6 -r Launchy.pro CONFIG+=release
    make
    sudo make install

qt6-base-dev provides qmake6, Qt Widgets, and Qt Network. qt6-5compat-dev
provides the Qt 5 compatibility module. libx11-dev provides the X11 headers
used by the Linux platform code. make install uses prefix /usr: the launchy
binary goes to /usr/bin, skins to /usr/share/launchy/skins, and plugins to
/usr/lib/launchy/plugins.

A current Qt 6 kit from the Qt online installer uses the same make steps.
For Qt 6.8 this is the gcc_64 component, including the Qt 5 Compatibility
Module. Call that kit's qmake (adjust the patch number if the installer
used a different 6.8 release):

    ~/Qt/6.8.3/gcc_64/bin/qmake -r Launchy.pro CONFIG+=release
    make
    sudo make install

To build a deb package, install dh-make and svn, then from Launchy11 run:

    cd linux
    ./build_deb.sh 3.0

linux/build_deb.sh exports the tree with svn, then runs qmake and
dpkg-buildpackage. The qmake on PATH for that script has to be the Qt 6
qmake.


Building on macOS:

Install a current Qt 6 kit for macOS, including the Qt 5 compatibility
module. Either of these provides it:

    The Qt online installer, Qt 6.8, macOS component.
        qmake is at ~/Qt/6.8.3/macos/bin/qmake
        (the 6.8 patch number in the path follows the installer).
    Homebrew: brew install qt
        qmake is at $(brew --prefix qt)/bin/qmake

Put that qmake on PATH. The kit's clang mkspec is the one qmake uses.

    qmake -r Launchy.pro CONFIG+=release
    make
    make install

make install copies skins into release/Launchy.app and runs mac/deploy,
which calls macdeployqt. Copy release/Launchy.app to the Applications
folder to run it.

To build a disk image, from the Launchy11 directory:

    cd mac
    sh mkdmg

The image is written in the mac directory.


Building on Windows:

Requirements:

1) Visual Studio 2022 with the "Desktop development with C++" workload.
   That workload provides the MSVC compiler, nmake, and the Windows SDK.
2) Qt 6.8 for MSVC 2022 64-bit, including the Qt 5 Compatibility Module.
   Install it with the Qt online installer:
   https://www.qt.io/download-qt-installer
   The kit directory looks like C:\Qt\6.8.3\msvc2022_64. The patch number
   in that path follows the installer.

Open the x64 Native Tools Command Prompt for VS 2022 from the Start menu.
In that prompt, add the Qt kit's bin directory to PATH, change to the
Launchy11 directory, and build. Adjust the Qt path if the installed patch
differs:

    set PATH=C:\Qt\6.8.3\msvc2022_64\bin;%PATH%
    cd \path\to\Launchy-Remastered\Launchy11
    qmake -r Launchy.pro CONFIG+=release
    nmake

qmake writes Makefiles and nmake compiles them. The executable is
release\Launchy.exe and the plugins are release\plugins. The Visual Studio
2005 solution files checked into the tree stay as they are.

Copy the skins next to the executable before launching. Launchy reads them
from release\skins:

    xcopy /E /I skins release\skins

Run release\Launchy.exe from that same prompt so Windows finds the Qt DLLs
in the kit's bin directory.

To copy the Qt libraries and the platform plugin into the release directory:

    windeployqt release\Launchy.exe
